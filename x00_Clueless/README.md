### **What You Must Be Able To Do**

- [ ] **Master:** Explain the boot process: POST → BIOS/UEFI → Boot loader → OS
- [ ] **Master:** Identify storage types: HDD vs SSD vs NVMe by appearance and specs
- [ ] **Know Well:** Configure BIOS/UEFI settings: boot order, virtualization, secure boot
- [ ] **Master:** Understand RAID levels: when to use RAID 0, 1, 5, 10
- [ ] **Know Well:** Calculate storage: understand capacity, speed, and form factors
- [ ] **Know Well:** Troubleshoot hardware: identify failing components (RAM, HDD, PSU)
- [ ] **Master:** Read system specs: CPU cores/threads, RAM type/speed, storage type
